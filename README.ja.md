# Just Translate

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語** | [한국어](README.ko.md) | [العربية](README.ar.md)

Chrome / Edge 向けの、ローカルファーストな対訳 Web ページ翻訳拡張機能です。訳文が各段落のすぐ下に表示されるので、原文と訳文を並べて読めます。訳文のみの表示にも切り替えられます。

アカウント登録もログインもサブスクリプションも不要です。インストールしたらすぐに Google または Microsoft の無料チャネルで翻訳でき、自分の OpenAI Chat Completions API や Anthropic Messages API もつなげられます。リクエストは拡張機能から選択したサービスへ直接送られ、開発者のサーバーは経由しません。

![日本語の記事を英語に翻訳し、各段落の下に訳文を表示した画面](docs/images/bilingual.png)

## なぜ作ったのか

Web ページの翻訳は単純な作業のはずなのに、多くの対訳翻訳拡張機能は使う前にアカウント作成とログインを求めてきます。Just Translate はその手順をなくしました。インストールすれば、すぐに読み始められます。

## 主な機能

- **対訳表示**：訳文は原文の段落の下に、ページのレイアウトを引き継いで表示されます。「原文 + 訳文」と「訳文のみ」を切り替えられます。
- **設定不要の無料エンジン**：Google 翻訳（デフォルト）と Microsoft Translator は、アカウントも API キーもブラウザの Cookie も使いません。
- **自分の AI を使える**：OpenAI、Anthropic、Gemini、Grok、Kimi、GLM、Xiaomi MiMo、DeepSeek、Qwen、そして `localhost` のローカルサーバーを含む互換エンドポイントに対応。プロファイルごとにプロンプトと思考設定を指定できます。
- **全文翻訳**（AI のみ）：読み込み済みの本文を 1 回のリクエストで送るので、段落をまたいだ用語や指示語の一貫性が保たれます。
- **選択範囲の翻訳**：テキストを選択して右クリックすると、選択範囲の近くにポップオーバーで結果が表示されます。iframe や編集可能な領域でも使えます。
- **クイック翻訳**：貼り付けたテキストをすぐ翻訳。画像入力に対応した AI モデルなら画像も翻訳できます。
- **表示領域を優先**：画面に見えている部分を先に翻訳し、次の画面、残りの順に進みます。動的に追加されたコンテンツも順次翻訳します。
- **サイトルール**：特定ドメインの自動翻訳、ドメインや `*.example.com` ワイルドカードでの除外。
- **ローカルキャッシュ**：訳文は SHA-256 をキーに IndexedDB へ 72 時間キャッシュされます。
- **勝手にエンジンを切り替えない**：エンジンが失敗しても、ページのテキストを別のサービスへ黙って送り直すことはありません。再試行や切り替えはユーザーが決めます。
- `Alt + T` ショートカット、ライト / ダークテーマ。UI は英語、簡体字中国語、フランス語、ドイツ語、アラビア語に対応しています。

## プライバシー

- 開発者のサーバーは一切経由しません。リクエストは拡張機能のバックグラウンドから Google、Microsoft、または設定した AI エンドポイントへ直接送られます。
- API キーは `chrome.storage.local` に保存され、拡張機能の信頼されたコンテキストからしか読めません。Web ページのコンテンツスクリプトからはアクセスできません。
- キャッシュには API キーも原文の平文も保存しません。
- 段落内のコードや `translate="no"` の部分はローカルのプレースホルダーに置き換えられ、翻訳サービスには送られません。

無料チャネルは公式の Google Cloud Translation / Azure Translator API ではなく、一般向けの Web エンドポイント（`translate.googleapis.com` と Bing Translator）を使っています。レート制限や仕様変更で使えなくなる可能性があります。機密性の高いサイトでは翻訳を有効にしないか、除外リストに追加してください。

詳しくは [PRIVACY.md](PRIVACY.md)（中国語）をご覧ください。

## インストール

ソースからビルドします（Node.js 22.12 以上）：

```bash
npx -y pnpm@10.34.5 install
npx -y pnpm@10.34.5 build
```

その後：

1. Chrome なら `chrome://extensions`、Edge なら `edge://extensions` を開きます。
2. デベロッパーモードをオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、`dist` ディレクトリを選択します。
4. 任意の HTTP/HTTPS ページを開き、ツールバーのアイコンをクリックするか、右クリックから翻訳を開始します。

AI エンジンを使う場合は、拡張機能の設定 →「AI 設定」でプロバイダーを選び、API キーを貼り付けてください。
