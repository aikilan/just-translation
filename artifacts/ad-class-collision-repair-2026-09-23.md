# 通用广告类名误判修复验收

## 根因与范围

已在用户 Chrome 的目标 Gmail 邮件确认：正文祖先为可见的 `div.adn.ads`，位于主内容区、顶层文档中，没有 `translate=no` 等保护标记。共享采集器原来的 `[class~="ads" i]` 规则直接剪掉整个子树，因此关闭 AdGuard 无效。

生产修改仅删除 `ad`、`ads`、`advert`、`advertisement` 四条通用 class 过滤规则并添加注释。保留明确广告属性/ID、隐藏、编辑区、导航、受保护文本边界。不新增域名规则、依赖、设置或兼容分支。

取舍：只用上述 class 标记的真实广告可能进入候选；类名本身不足以证明内容应被整块排除。

## 测试先行

- 修改生产代码前：5 个类名用例及 1 个动态新增正文用例失败，11 个明确保护边界用例通过。
- 修改后定向测试：3 个文件、104 个测试通过。
- 最终 `pnpm check`：68 个文件、877 个测试通过，ESLint、TypeScript、生产构建及构建验证通过。
- `git diff --check` 通过。
- 覆盖只读/实际/分片/局部采集一致性、嵌套邮件布局表格、父子无重复、原链接身份与事件保留、精确恢复、动态插入只请求一次。
