# 全文翻译审查问题修复与验收

2026-09-14。在已有全文翻译实现上修复审查确认的三个行为问题和一个协议校验缺口。保留原工作区变更，没有新增依赖、权限、全局设置或兼容消息。

## 已修复

- 自动启动由内容脚本持有独立的取消信号。用户开始、切换、停止、恢复或重试任务，以及 pagehide，都会使尚未执行的自动启动失效。设置响应迟到时不再覆盖用户操作；状态查询和展示方式调整仍允许原本有效的自动启动。
- 初次采集和只读复核共用正文规则。复核重新检查真实原文子树，将扩展包装视为透明容器，排除扩展译文；发现新增裸文本时返回未建立锚点的单元，不修改宿主 DOM。删除了直接接受已有 source 的 includeTranslatedSources 分支。
- 分帧只读扫描期间若发生 DOM 变化，在提交前补一次同步只读核对，然后在同一调用栈内发请求或揭示译文。导航动画不需要停止；已扫描区域的新段落仍不能绕过校验。回填写入继续分帧执行。
- 每次只读复核重新分析正文，避免跨阶段分析缓存遗漏宿主自定义属性造成的 CSS/可见性变化。
- 利用现有 JSON 库的顶层 value 回调，要求唯一的 translations 数组。重复字段整次失败，继续保留原有 ID、译文、标记、正常结束和限额校验。

## 真实扩展验收

使用最终构建的 dist、Chromium 153.0.8010.12，以及全新隔离目录 `/tmp/just-translate-fixes-final-20260914`。本地模拟服务为 `scripts/browser-fixture-server.mjs`，验收时地址 `http://127.0.0.1:64243`。通过真实扩展消息驱动页面和后台，验证真实 DOM 与 HTTP；键盘重试使用浏览器 Space 按键。本轮没有重复原生右键菜单操作，入口本身未在此次修复中修改。

| 场景 | 实测结果 |
| --- | --- |
| 606 个正文单元，导航持续 requestAnimationFrame 更新 | 1 次 HTTP；606 段全部完成；动画运行 109 帧；可见译文数量只出现 0 和 606 |
| 原文字相同，但 2 个单元变为 3 段 | 旧结果被拒绝，0 译文、0 隐藏原文，显示全文重试入口 |
| 在上述失败入口按 Space | 重新采集为 3 单元并完成；两次请求的单元数为 `[2, 3]` |
| 自动设置响应迟到于手动全文开始 | 保持 full-document，1 次 6 单元请求，完整完成 |
| 自动设置响应迟到于恢复原文 | 保持 idle，0 HTTP 请求 |
| 重复 translations 字段 | 6 单元及 3 单元场景均整次失败，各 1 请求；原文保留，正文只显示通用重试提示 |
| 普通翻译与缓存 | 普通请求为 `[4, 2]`；恢复后再翻译，HTTP 总数仍为 2 |
| 全文请求期间显式切回普通模式 | 全文请求中止 1 次；普通模式通过缓存完成 6 段，没有迟到覆盖 |

自动启动时序验收只人为延迟了隔离后台的一次真实 storage.local.get 返回，然后恢复原方法；没有替换控制器或自动启动实现。重复字段由 Playwright 在 HTTP 层提供模拟 SSE，仍经过真实后台请求和解析链路。所有配置均为本地模拟配置，没有使用用户凭证或真实 AI。

606 单元样例的 PerformanceObserver 未记录到 50ms 以上的 long task；这是该样例和当前机器上的测量，不代表所有网页的耗时上限。此次模拟验收证明请求、协议和渲染流程，不评价真实模型语义质量。

首次验收曾复用一个在构建完成前启动过的隔离目录，出现新内容脚本与旧后台混用。后续改用上述全新目录，重复字段、动画和结构变化等最终记录均在新目录重新验收。最终隔离浏览器和模拟服务均已关闭。
