# 快捷翻译验收记录

日期：2026-09-23。实现基于用户确认的 popup 入口与网页居中弹窗设计。

## 交付行为

- popup 的主翻译按钮下方新增「快捷翻译」，与「全文完整翻译」并排。收到网页成功打开弹窗的确认后才关闭 popup；失败留在 popup 展示提示。
- 网页中央显示独立编辑器，支持多行输入、键盘粘贴、剪贴板粘贴按钮、显式提交、停止、重试和复制译文。Ctrl/Cmd+Enter 提交，Esc 关闭。
- 弹窗中的引擎和目标语言仅作为本次请求参数，不写入网页翻译设置。关闭后在同一文档保留草稿和成功结果，刷新后清除。
- 快捷翻译与划选翻译共用后台文本翻译服务、限流和重试，取消请求按功能及文档隔离。密钥保留在后台，不随弹窗设置或结果返回。
- 原有整页翻译不因快捷翻译打开或关闭而启动、停止或恢复。普通网页未连接时也可直接打开，无需刷新；已排除站点允许显式快捷翻译；浏览器内部页面禁用入口。
- 沿用现有依赖，新增 `scripting` 权限以独立加载弹窗，HTTP/HTTPS 网站访问范围不变。弹窗按需加载，支持五种现有界面语言和响应式布局。

## 自动化检查

最终 `pnpm check` 通过：ESLint、75 个测试文件 / 935 个测试、TypeScript、Vite 构建、后台 bundle 与快捷翻译注入产物校验。

新增测试在实现前先运行并确认失败，覆盖：

- popup 成功确认、失败提示、重复点击锁、排除站点和受限页面。
- 网页没有消息接收端或返回无效状态时，快捷翻译入口可用；加载失败可重试，加载器完成后仍等待弹窗打开确认。
- 独立入口自行初始化语言、复用弹窗及处理页面离开；两次注入绑定同一文档，模块加载期间离开页面不会再打开。
- 构建校验直接运行产物中的加载器和序列化注入函数，避免 Vite 预加载助手引入闭包依赖。修复前该校验复现 `F is not defined`，修复后通过。
- 仅显式提交、逐请求语言/引擎、可信配置解析、免费通道长文拆分、密钥不返回。
- 请求预检阶段取消、页面导航、快速关闭重开、迟到响应以及与划选翻译同 ID 的取消隔离。
- 输入修改清除旧译文、复制/粘贴竞争、剪贴板读取失败与手动粘贴提示。
- 原生弹窗挂载顺序、输入焦点、Esc、纯文本结果、宿主网页元信息保护和 RTL。
- 草稿选中的 AI 配置被删除后，显示「当前翻译配置不存在」并禁用提交，直到用户重新选择引擎。
- 普通 HTTP 环境没有 `crypto.randomUUID` 时仍可提交、取消；控制器重建后请求 ID 保持不同，旧结果不能覆盖新请求。
- 自定义目标语言为空或全空格时，按钮、快捷键和控制器提交均不发起请求；编辑语言立即清除旧译文，选择预设语言后恢复提交。
- 自定义输入恰好经过预设名称（如 `French`）时不会失去输入框，可继续输入 `French Canadian` 并通过快捷键提交当前草稿；设置页仍仅在有效失焦或回车后提交保存。

复查及本轮修复检查中，原有 `controller-optimizations.test.ts` 的 `continues old-order dispatch if another scroll invalidates a slow viewport lookup` 出现过时序断言失败（预期第 7 个批次、实际 6 个）。该用例单独复跑以及随后的完整 `pnpm check` 均通过；本次没有修改该用例或视口调度逻辑。

## 验收边界

- 真实浏览器验收使用本地 mock 服务，验证消息、HTTP、取消与界面链路，不代表外部 Google、Microsoft 或 AI 服务的实时可用性和翻译质量。
- 剪贴板读取成功路径由自动化测试覆盖；浏览器验证了权限拒绝提示、系统键盘粘贴及真实复制写入。
- 深色外观和多语言沿用现有规则与控件；浏览器视觉验收为中文浅色，RTL 的宿主隔离由自动化测试覆盖。
- `dist` 已更新，版本保持 0.3.34。本次未发布、未递增版本，也未重载用户日常 Chrome 中的扩展。
