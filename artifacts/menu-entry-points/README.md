## 真实扩展验收

使用隔离 Chrome for Testing、当前 dist 和项目本地模拟 SSE 服务。未使用真实 AI 或用户密钥。

1. 原生右键菜单的无障碍树只显示一个一级翻译项，没有全文项和扩展父级子菜单；实际点击后普通模式完成 6 / 6 个段落。
2. 在隔离扩展中预置原全文菜单，重新加载扩展后再次打开原生右键菜单，确认旧项已移除且仍只有一个一级入口。
3. 实际打开工具栏弹窗，按 Tab 三次聚焦“全文完整翻译”，按 Enter 启动。弹窗显示“全文翻译中”和“停止翻译”，随后完整回填 6 / 6 个段落，模拟服务仅收到一次包含 6 段的 HTTP 请求。
4. 实测初始 500px 高度导致中间区域溢出 23px，因此调整到 540px。最终浅色和深色实测内容区均为 `clientHeight = scrollHeight = 439`，无垂直滚动；宽度 380px，无横向溢出。深色检查同时启用减少动态效果。
