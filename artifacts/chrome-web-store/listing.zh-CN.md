# Chrome 应用商店发布资料

## 基本信息

- 名称：只是翻译
- 版本：0.3.28
- 默认语言：简体中文
- 类别：效率工具
- 可见性：公开
- 定价：免费

## 摘要

无需 API 配置即可使用 Google / Microsoft 免费通道翻译网页，也可连接自己的 AI。

## 详细说明

只是翻译是一款本地优先的网页翻译扩展。全新安装默认使用 Google 免费通道，也可手动切换 Microsoft 免费通道，或连接自己的 OpenAI / Anthropic 协议 AI API。你可以在原文下方阅读译文，或切换为仅译文模式。请求直接发送给界面中明确选择的服务，不经过开发者中转翻译服务。

主要功能：

- 普通翻译按当前阅读位置优先处理，译文逐段显示；失败会自动重试一次
- Google / Microsoft 免费通道支持普通网页、动态内容、自动翻译和划选翻译，无需账号或 API Key
- 全文完整翻译由用户配置的 AI 一次理解当前已加载正文，保留跨段上下文和重复段落
- 双语与仅译文显示，可随时停止、继续或恢复原文
- 支持多个 AI 配置、自定义翻译 Prompt、目标语言和 1–6 路并发
- 支持精确域名自动翻译、精确域名与通配子域名排除规则
- 支持动态内容补译、右键菜单与 Alt + T 快捷键

数据与隐私：开始翻译后，当前网页中需要翻译的文本会直接发送到用户明确选择的 Google、Microsoft 或自定义 AI 服务。API 地址、API Key、模型和偏好仅保存在当前浏览器；开发者不会接收网页内容、密钥或翻译结果。请勿在敏感页面启用翻译，或先将相应网站加入排除规则。

Google / Microsoft 选项使用非官方消费端免费接口，可能限流、变更或失效，可用性不受保证；失败时不会自动切换服务。自定义目标语言和全文上下文翻译需要用户配置有效的 AI API。

## 单一用途

在用户浏览的网页中识别正文，使用用户明确选择的翻译服务翻译，并将译文展示在原文附近。

## 权限用途说明

- `storage`：在当前浏览器保存 AI 配置、阅读偏好、站点规则、临时会话状态和译文缓存。
- `activeTab`：在用户操作工具栏、右键菜单或快捷键时，与当前标签页通信并启动翻译。
- `contextMenus`：提供标明当前翻译引擎的网页和划选翻译右键入口。
- `alarms`：定期清理超过 72 小时的本地译文缓存。
- `webNavigation`：将任务绑定到当前文档，并在导航后取消旧任务，避免旧译文写入新页面。
- `http://*/*`、`https://*/*`：识别和展示用户所选普通网页的译文，访问固定的 Google/Bing 免费通道，以及访问用户自行配置的 AI API 地址。

## 远程代码声明

否。所有可执行代码都包含在扩展包内；远程 API 响应只作为翻译数据解析和展示，不会作为代码执行。

## 用户数据披露建议

- 身份验证信息：是。用户自备的 API Key 在本地保存，并仅发送给对应的自定义 AI 服务商用于鉴权。Google/Microsoft 免费通道不使用用户账号或 API Key；Bing 临时令牌仅保存在 Service Worker 内存中。
- 网站内容：是。需要翻译的网页正文会发送给用户明确选择的 Google、Microsoft 或自定义 AI 服务商。
- 浏览记录：扩展只在本地处理当前页面 URL/域名及用户填写的站点规则，不建立或上传浏览历史。如后台将“当前网页信息”归入浏览记录，应如实勾选。
- 个人身份、健康、财务、付款、位置、个人通信、用户活动：否。

所有披露的数据仅用于扩展的单一翻译用途；不出售，不用于个性化广告或信用评估，也不用于与单一用途无关的场景。

## 审核说明

扩展没有开发者运营的账号或翻译后端。安装后打开任意普通 HTTP/HTTPS 文章页面，通过工具栏弹窗点击“翻译此网页”，即可使用默认 Google 免费通道。也可在“翻译引擎”中选择 Microsoft。右键菜单标题会显示当前接收方，划选翻译结果也会显示实际引擎。

“全文完整翻译”只支持用户配置的 AI，免费通道下该入口保持可见但禁用。审核 Google / Microsoft 普通和划选翻译无需第三方 API 凭据。两个选项使用非官方消费端接口，不携带浏览器 Cookie、不读取用户账号、不执行远程脚本；接口可用性不受开发者保证。
