# 划选翻译验收

2026-09-16，基于本地 `dist`，使用独立用户目录的 Google Chrome for Testing 和本地 SSE 模拟服务。未调用用户的真实 AI API，未重新加载用户日常使用的 Chrome 扩展。

## 原生右键操作

通过原生浏览器右键菜单实际点击“使用「只是翻译」翻译”，已验证：

- 主文档只显示一个直达入口，选中文字后在选区附近打开结果浮窗。
- 输入框选中文字、同源 iframe、跨域 iframe 均能翻译，结果显示在选区所属文档内。
- 复制按钮显示“已复制译文”，Esc 关闭浮窗。
- 测试主站已加入排除列表，主动划选仍成功。
- 主页面调用记录只有一个 `selection` 单元，原文为 `Selected paragraph about solar energy.`，未包含相邻正文。

## 扩展运行时检查

后续场景通过页面选区事件和定向扩展消息驱动实际内容脚本、后台、供应商队列及 HTTP/SSE 链路。最终构建的结果见 `browser-results.json`：

- 长译文浮窗宽 380px、高 480px；正文独立滚动，关闭和复制按钮保持可见。浅色、深色截图已检查。
- 第一次 HTTP 失败后自动重试成功；最终失败后手动重试成功。
- 关闭浮窗、替换选区、页面导航均实际中止在途 HTTP 请求。
- 新选区结果不会被旧请求覆盖。
- 类 HTML 内容按纯文本显示，不创建图片或脚本节点。
- 配置缺失时不发送 HTTP 请求；原文节点移除后浮窗关闭。
