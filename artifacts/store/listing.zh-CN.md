# Chrome Web Store listing: 简体中文

## 名称和摘要

来自安装包（`_locales/zh_CN/messages.json`），无需在后台填写。

- 名称：只是翻译
- 摘要：双语对照翻译网页，无需注册登录。可用 Google 或 Microsoft 免费翻译，也可连接自己的 AI。

## 详细描述

```text
双语对照阅读任意网页，无需注册，无需登录。

只是翻译把译文直接显示在每个段落下方，原文和译文对照阅读，也可以随时切换为仅显示译文。装上就能用，没有任何需要注册的东西。

为什么选择只是翻译
• 不用注册，不用登录，没有订阅。
• 开箱即用 Google 翻译或 Microsoft 翻译免费通道，不需要 API Key。
• 没有中间商：请求从你的浏览器直接发往你选择的服务，不经过开发者的服务器。
• 开源（AGPL-3.0），任何人都可以检查数据发往了哪里。

功能
• 双语阅读：译文显示在原文段落下方，沿用网页原有排版。
• 可视区优先：先翻译屏幕上的内容，再翻译页面其余部分；新加载的内容会自动补译。
• PDF 阅读器：在内置阅读器中打开 PDF，原版页面与译文对照阅读，滚到哪页翻哪页。
• YouTube 双语字幕：在播放器里点一下，每句字幕下方显示译文，边播放边翻译。
• 划选翻译：选中文字后右键，译文显示在旁边。
• 快捷翻译：在弹窗中粘贴文字即可翻译。
• 接入自己的 AI：用自己的 API Key 连接任意 AI 服务，也可以连接本机运行的模型。
• 全文完整翻译：用你的 AI 一次理解整篇文章，术语前后一致。
• 站点规则：为指定网站开启自动翻译，或排除不想翻译的网站。
• Alt + T 快捷键，浅色 / 深色外观，界面支持多种语言。

隐私
API Key 和设置只保存在你的浏览器里。网页文本只会发给你选择的翻译服务，某个服务失败时也不会悄悄改发给其他服务。Google 和 Microsoft 免费选项使用的是公开的网页接口，而不是官方云 API，可能被限流或变更。请避免翻译敏感页面，或将它们加入排除列表。

源代码：https://github.com/aikilan/just-translation
```
