| 角色 | 浅色颜色 | 深色颜色 | 字号 / 字重 |
| --- | --- | --- | --- |
| 页面标题 | #222 | #f2f2f2 | 28px（窄屏 24px）/ 700 |
| 模块标题 | #222 | #f2f2f2 | 18px / 600 |
