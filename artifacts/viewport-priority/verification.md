# 可视区域优先翻译验收

日期：2026-09-15。基线：`main` / `5ffcee5`。仅调整普通分段翻译。

## 实现

- 优先发现当前可视区正文，再发现其余正文；已发现的阅读节点不重复分析。
- 可视区候选解析、逻辑请求（含重试）和译文渲染完成后，才放行屏外任务。
- 屏外阶段可使用六路并发。滚动不取消在途请求，补位前按最新可视区重排；候选解析期间再次滚动也会复核。
- 横向视口和祖先滚动容器裁剪参与可视判定，屏外父容器不会导致其可视后代漏采。
- 复用缓存、去重、自动重试、动态正文与停止恢复生命周期。全文完整翻译行为不变。
