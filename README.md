# 只是翻译

一个本地优先的 Chrome / Edge 网页双语翻译扩展。无需 API 配置即可使用 Google 或 Microsoft 免费翻译通道，也支持你自己配置的 OpenAI Chat Completions 或 Anthropic Messages API。扩展不经过开发者中转翻译服务。

## 翻译引擎

- 全新安装默认使用“Google 翻译（非官方免费通道）”，也可手动切换为“Microsoft 翻译（非官方免费通道）”；已有安装继续使用原来选中的 AI 配置，不会把既有自动翻译站点改发给免费通道。
- 两个免费通道适用于普通网页、动态内容、站点自动翻译、划选翻译和快捷翻译，支持简体中文、英语、日语、韩语、法语、德语、西班牙语和阿拉伯语。自定义目标语言仅支持 AI 配置。
- 免费通道使用 Google/Bing 的消费端接口，并非 Google Cloud Translation 或 Azure Translator 官方 API。它们不需要账号、API Key 或浏览器 Cookie，但可能限流、变更或失效，可用性不受保证。
- 翻译失败时不会自动切换引擎。用户需要明确重试或手动选择其他引擎，避免网页文本在没有提示的情况下发送给另一服务。
- AI 配置仍独立保存，可用于普通翻译和“全文完整翻译”；免费通道下全文入口会保留但禁用。

## 全文完整翻译

选择有效的 AI 配置后，点击工具栏中的「只是翻译」，在弹窗主按钮下方选择「全文完整翻译」。扩展会收集当前页已经加载的正文，包括屏幕外内容，让 AI 在一次请求中结合全文理解跨段指代与术语，再将全部译文按段落统一显示。免费通道不接收全文上下文请求。普通页面右键菜单显示当前引擎名称；选中文字后的菜单也会在发送前标明接收方。

## 划选翻译

在网页上选中一段文字，右键点击“翻译已选内容 · 当前引擎名称”，选区附近会立即显示结果浮窗。支持 HTTP/HTTPS 主页面、同源及跨域 iframe，以及输入框、文本域和可编辑内容；iframe 的浮窗显示在该 frame 内。

- 只发送选中的文字，保留换行，沿用当前翻译引擎、目标语言和自动重试次数；使用 AI 时同时沿用该配置的 Prompt。划选翻译不使用段落缓存、不逐字显示，结果顶部会显示实际使用的引擎。
- 译文按纯文本展示，原文默认折叠；可复制译文、展开原文、失败后重试。长内容在浮窗内滚动，支持深浅色外观。
- 通过关闭按钮、Esc 或点击所属文档的浮窗外部关闭；关闭、重新划选翻译及页面导航会取消旧请求，旧响应不会覆盖新结果。
- 主动划选翻译允许在已排除的网站执行，不修改网页原文，也不启动或停止整页翻译。
- 不支持浏览器内部页面、PDF 阅读器、`file://` 和 `about:blank/srcdoc` iframe。配置缺失时在浮窗显示设置指引。

|                  | 普通翻译                                      | 全文完整翻译                                     |
| ---------------- | --------------------------------------------- | ------------------------------------------------ |
| 请求             | 小批次，逐步显示                              | 整篇单次请求，完整校验后显示                     |
| 长段落与重复文字 | 安全分片、同文去重                            | 不拆分、不去重，每个位置独立保留                 |
| 缓存与失败       | 使用段落缓存，可配置自动重试次数（默认 1 次） | 首轮不读写段落缓存、不自动重试；补译复用普通队列 |
| 动态内容         | 按阅读偏好自动补译                            | 首轮完成后按阅读偏好增量补译                     |
| 支持引擎         | Google、Microsoft 免费通道或 AI 配置          | 仅有效的 AI 配置                                 |

全文模式沿用当前 AI 配置、目标语言和显示方式。首轮按一次全文请求统一显示；请求期间独立新增的内容排队，已采集原文被修改、移除或隐藏则丢弃首轮结果并提示重新全文翻译。首轮失败不自动重启。

开启「动态内容翻译」（默认开启）后，全文完成后的新增与更新内容使用普通分段队列补译，保留其他已完成译文。补译不携带首轮整篇上下文，使用段落缓存、并发和自动重试设置；失败可以单项或批量重试，不重新提交整篇。配置或目标语言变化时暂停补译并提示重新翻译。关闭动态翻译后不自动补译。

弹窗区分「全文翻译中」和「正在补译新内容」，可停止、重新全文翻译及恢复原文。停止会取消请求、排队任务和自动补译监听，已完成的译文保留；标签译文存续期间仅跟踪对应文字节点的网页修改，用于安全恢复，不触发翻译请求；恢复原文会清理首轮和补译的呈现。正文上的「重试全文」支持点击、Enter 和空格；控件内不插入重试按钮，请从扩展弹窗重试。`Alt + T` 保持翻译／恢复行为。

全文模式不会主动滚动、翻页或抓取其他页面，也不会在超长时降级拆段。全文请求体上限为 1 MiB，SSE 总量上限 16 MiB，单事件上限 1 Mi 字符，译文 JSON 上限 2 Mi 字符；HTTP 超时 120 秒，不包含排队时间。模型上下文不足或输出截断会明确提示，需更换合适的模型后重试。

## 快捷翻译

打开工具栏中的「只是翻译」，点击「快捷翻译」，在当前网页中央打开翻译弹窗。可直接输入多行文字、使用 Ctrl/Cmd+V，或点击「粘贴」读取剪贴板；点击「翻译」或按 Ctrl/Cmd+Enter 后才发送输入内容。

- 原文与译文并排展示，窄视口自动切为上下布局；支持复制译文、清空、停止和失败重试。剪贴板读取被拒绝时，仍可在输入框中手动粘贴。
- 初次打开沿用当前引擎与目标语言，此后的弹窗内选择仅用于快捷翻译，不改变网页翻译设置。支持两个免费通道和已配置的 AI 服务；AI 沿用该配置的 Prompt，所有引擎沿用自动重试设置。
- 点击关闭或按 Esc 取消未完成请求，同一网页内重新打开保留输入与成功结果。修改原文、引擎或目标语言会清除旧结果；刷新或离开网页后不保留草稿，不持久化翻译历史。
- 快捷翻译可在已排除的网站主动使用；普通网页即使显示「未连接」也可直接打开，无需先刷新网页。不启动或停止整页翻译。浏览器内部页面、扩展商店等无法注入内容脚本的页面不可用。

自动化与隔离浏览器的验收范围见 [快捷翻译验收记录](artifacts/quick-translation/verification.md)。

### 图片翻译

在快捷翻译弹窗中选择支持图片输入的 AI 配置后，会显示「上传图片」。可只选择图片，也可同时输入文字；点击「翻译」后发送给所选服务，结果以可复制的文字展示。图片内容不会覆盖回原图，不自动扫描网页中的图片。

- 内置能力表按供应商、完整模型 ID、官方 API 地址和协议自动匹配，不在运行时联网探测。已确认不支持或尚未确认的内置模型隐藏图片入口；免费翻译通道不支持图片。
- 自定义模型、模型别名和中转地址需要在 AI 配置中手动开启「支持图片输入」，默认关闭。更改供应商、协议、地址或模型后会重置此开关，须重新确认。
- 每次接收一张 PNG、JPEG 或 WebP，原文件和转换后文件均不超过 4 MiB，边长不超过 4096 像素，总像素不超过 1600 万。WebP 在本地转为 PNG；文件内容和尺寸均会在发送前验证。
- 图片只保留在当前页面的快捷翻译草稿中；选择和预览不产生翻译请求，不写入存储、缓存或日志。点击移除释放图片；关闭弹窗取消请求，重新打开保留草稿；页面刷新清除草稿。
- 快捷弹窗在扩展隔离环境中使用封闭 Shadow DOM，文件输入框与图片预览不向宿主网页暴露 DOM 引用。
- 已选图片时切换到不支持图片的模型，会保留预览并禁止发送，直至移除图片或换回支持的模型。无文字时显示「未识别到可翻译文字」。HTTP 400 等确定性错误不自动重试；限流、网络和临时服务故障沿用重试次数。

能力表与官方资料核对日期见 [`src/shared/image-capabilities.ts`](src/shared/image-capabilities.ts)，完整验收范围见 [图片翻译验收记录](artifacts/image-translation/verification.md)。

## 现有能力

以下小批次、段落缓存、同文去重和自动重试行为适用于普通翻译，以及全文完成后的增量补译。

- 将译文展示在原文段落下方；确认缓存未命中、请求入队后显示 spinner
- 在“原文 + 译文”和“仅译文”之间切换
- 处理标题、段落、列表、引用和表格单元格；短中文标签不设 20 字符门槛
- 按钮、筛选标签等界面文字始终仅显示译文，正文遵循双语／仅译文设置；等待或失败时保留原文字，保留图标、徽标、点击、焦点和禁用状态
- 正文优先采集：优先 `main` / `article`，跳过导航、网站页眉页脚、侧栏和广告，保留文章 header 内的标题及 flex 中的阅读文本；同时采集内容区按钮、筛选标签、表单说明和弹层选项
- 段落内代码和明确标记不翻译的片段使用本地占位符保护，实际内容不发送给所选翻译服务；返回时校验标记完整性并以纯文本安全恢复
- 文本噪声过滤：不翻译日期、URL、邮箱、单个大写品牌词和泄漏到 DOM 的脚本文本
- 同页相同原文只请求一次，译文同步映射到所有对应节点
- 长文本 Unicode 与占位符安全分段、上下文分组、批量请求和严格的译文 ID 校验；已校验的成功项立即交给有序渲染队列，缺失、空白或保护标记损坏的项独立补译
- AI 小批次：每批最多 4 段，可见区/下一屏/后台字符预算分别为 1200/1800/2400
- 免费通道：每次请求只发送一个分片，最多 1000 个 UTF-16 字符；最多 2 个并发、每个服务主机每秒最多启动 2 次请求，单次 HTTP 尝试统一为 20 秒
- 使用 Chat Completions SSE 增量接收：完整 JSON 译文项校验后立即推送，同一长段落的所有分片齐全后才进入现有有序渲染；不展示半句或逐字刷新
- 流式连接中断只重试未成功的 ID，已校验结果不重发、不覆盖；未知/重复 ID 终止当前响应，已独立成功的段落保留，未完成节点提供重试
- 首个批次立即发送；后续不足一批时最多合并等待 20ms，批次装满或采集完成立即发送，减少渐进采集造成的碎片请求
- 设置页「AI 配置 → 单页翻译并发数」可选择 1–6（默认 4），用于下一次普通翻译和手动重试；免费通道会进一步限制为最多 2 路。降低并发仅减慢处理速度，不限制为仅翻译可视区；AI 请求按 API origin 统一限制最多 6 路 HTTP 并发、任意一秒最多发起 6 次请求，多个标签页、模型和配置共享额度
- 普通翻译优先发现当前可视区正文，页面中部启动同样优先翻译眼前内容；可视区的候选解析、请求及译文显示结束后，再处理下一屏与剩余正文
- 屏外翻译可使用全部已配置的页面派发槽；滚动只合并记录可视区变化，有空闲名额时按最新可视区补位，移出可视区的排队任务可降级，已发出的 HTTP 继续完成
- 当前阅读窗口内按 DOM 顺序显示；可视任务最终失败、跳过或源节点移除后继续后续正文，自动重试期间保持等待
- DOM 先采集可视区，再补充屏外正文；已发现节点跳过重复分析，首批最多 4 个节点；后续按最多 24 个节点 / 8ms 遍历预算切片，大段落的行内片段分析也可让出主线程；最多三个未完成候选解析分片并行推进，单片缓存查询不阻挡后续采集
- 连续正文中的行内链接与前后文字共同翻译，不再把链接单独抽走而漏掉周围句子；包含其他阅读块的布局容器不会被合并
- 嵌套段落前后的散落正文用可恢复的独立阅读单元收集，不丢正文、不重复翻译祖先；恢复后仍是原来的链接和文本节点
- 原文、保护标记及主要可见文本样式共享 DOM 分析快照，页面文字/样式变更立即使快照失效；隐藏文字和保护片段不参与主要字体判断
- 译文分片提交，每片最多 4 个节点；先读取原文排版再写入 DOM，片间让出主线程，保持既有阅读窗口顺序
- 目标语言必需文字系统未出现时直接进入翻译候选，省去无意义的统计语言检测；混合文本仍保留原有置信度校验
- 简繁中文转换保留 Hans/Hant 变体；无法确认与目标文字变体一致时交给 AI，不仅凭统计检测结果 `zh` 跳过
- 翻译完成只更新本批节点的展示模式，不反复扫描整页已翻译节点
- 动态新增、移除、显隐和文本变更后只渐进扫描变化子树，不重扫整页；插件渲染和节点重试不再丢弃同一时刻的页面变更
- 动态子树分别等待 800ms 稳定窗口，单节点重试期间继续收集变更，不让不断更新的相邻区域阻挡稳定段落
- 停止请求、恢复原始网页、按页面来源、翻译引擎、适配器策略版本、目标语言和原文隔离的 IndexedDB 译文缓存；Bing 临时令牌不会进入缓存键
- 缓存从首次写入起固定保留 72 小时，每三天自动回收过期记录
- 缓存查询使用只读事务，过期删除单独重验；译文展示和页面完成不等待写入，后台会话在有界写入收尾后清理，数据库打开失败不会永久锁死后续读取
- 翻译前后校验原文快照，页面变化时丢弃过期译文并有限重试
- 设置页「AI 配置 → 翻译失败重试次数」可选择 0–5 次（默认 1 次，0 表示关闭自动重试），所有引擎共用，自动保存并在下次翻译生效。HTTP 错误、断流、响应格式/ID 异常、单次请求超时及缺项补译共享同一额度，每批最多尝试「1 + 重试次数」次；只重发未成功的内容，取消或停止不重试，同一次任务不会跨引擎回退
- 自动重试前默认等待 400ms；429 的 Retry-After 同步暂停同 API 主机的排队请求，不截短服务商要求的等待时间
- AI 可见区、下一屏、后台的每次 HTTP 尝试分别限制为 20/30/60 秒；免费通道统一为 20 秒。等待队列不占用 HTTP 超时时间；重试和缺失项补偿同样经过后台限流
- 停止翻译、关闭标签页及页面导航同时取消旧文档的活动和排队请求；会话绑定浏览器文档 ID，同源翻页不会继续占用旧页面的请求槽
- 没有有效原文消费者的本地排队单元不再派发，整批消费者消失时取消后台批次；BFCache 恢复仅重新启动此前已启用翻译的页面
- 自动重试期间保留 spinner，重试额度耗尽后仍失败才在节点原位提示，支持点击或键盘单独重试
- 普通翻译出现失败后，可在弹窗或当前网页的右键菜单点击「重试全部失败」；仅重试点击时的失败段落，保留成功译文和已完成分片，所有批量重试请求共用所设并发上限。可停止，仍失败的段落可以再次重试。
- 右键「重试全部失败」仅在当前网页存在普通翻译失败项时显示；切换标签页、导航或失败清零后同步更新。存在两个菜单项时，Chrome 会将它们收进扩展子菜单。
- 长节点手动重试仅补失败或尚未发送的分片，成功分片保存在该节点任务进度中；后台配置指纹或原文变化后不复用旧分片，不新增内存译文缓存
- 翻译节点采用互不包含的叶子阅读单元，避免嵌套表格出现重复译文
- 连接测试会按所选协议验证接口、SSE 响应结构和非回显结果，并展示实际测试译文供人工确认
- 设置由后台统一保存并回传弹窗使用的配置状态
- 设置保存后会从浏览器存储回读并逐字段校验，弹窗会展示配置未生效的具体原因
- 翻译引擎选择与 AI Profiles 独立保存；支持多个 AI 配置，并可在弹窗中显式切换免费通道或某个有效 AI 配置
- 新配置依次选择供应商、接入协议（默认 OpenAI，可选 Anthropic），再填写 API 地址、密钥、模型及思考设置。覆盖 Gemini、Grok、OpenAI、Anthropic、Kimi、GLM、MiMo、DeepSeek、Qwen 和自定义供应商；未提供官方接口的协议组合须自行填写兼容中转地址。
- 模型建议在本地维护，也可手填。思考规则只匹配明确的供应商、协议和型号；可关闭的型号默认关闭，开启思考翻译时间较慢；始终思考的型号禁止关闭，不支持思考的型号不发送参数。未知型号自动模式不猜测参数，可在高级设置手动指定控制方式、强度和预算。
- 强度默认使用服务商默认；低强度不等于关闭。预算默认 2048，至少 1024，且小于实际输出上限。Anthropic 普通／选区／连接测试默认输出上限 8192，全文目标 65536，并按已知型号上限截小；未知型号默认 8192。高级设置可指定输出上限。
- 普通翻译、全文翻译、选区翻译和连接测试共用协议适配器；思考、强度、预算随「保存配置」提交。测试使用当前草稿，保存失败保留草稿。运行中的任务固定开始时的配置，缓存与失败重试按供应商、协议、端点和有效思考参数隔离。
- 已有配置保留原字段，缺少供应商／协议时显示待补全；补选保存后才能发起新翻译。不会根据域名推断供应商或自动迁移；缺少新契约的旧会话明确失效。
- 模型规则及官方文档来源见 `src/shared/providers.ts`；具体中转若不遵循官方参数，可手动覆盖控制方式或选择接口默认。服务商拒绝参数时保留真实错误，不自动换协议、换模型或降低强度。
- 每个 AI 配置可独立自定义翻译 Prompt；目标语言占位符可用，节点映射与 JSON 返回协议由扩展固定保护
- 支持为精确域名开启自动翻译，进入站点或翻页后无需手动触发
- 站点排除规则，支持精确域名和 `*.example.com`
- 页面右键菜单显示“立即翻译 · 当前引擎名称”，选中文字时显示“翻译已选内容 · 当前引擎名称”；若菜单标题更新失败，点击不会发送网页文字
- `Alt + T` 快捷键
- 浅色/深色外观

## 安装

### 直接加载已构建版本

1. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目的 `dist` 目录。
4. 打开普通 HTTP/HTTPS 网页，通过扩展弹窗或页面右键菜单即可用默认 Google 免费通道开始翻译。
5. 如需 Microsoft，可在“翻译引擎”中手动切换；如需全文上下文或自定义目标语言，再到“AI 配置”填写 API 地址、API Key 和模型，保存后设为当前使用。

更新已解压的扩展时，仅刷新设置页不会更新后台。先保留未保存的配置，在扩展管理页点击「只是翻译」的重新加载按钮，再重新打开设置页；需要翻译的网页也应刷新。若保存提示后台响应无效，按此步骤重新加载，避免新界面与旧后台同时运行。

自定义 AI 的 API 地址可以是：

- `https://api.openai.com`
- `https://api.openai.com/v1`
- `https://api.openai.com/v1/chat/completions`

扩展最终都会请求 Chat Completions 端点。
接口必须支持 `stream: true` 并返回 `text/event-stream`；设置页测试连接与正式翻译使用同一解析器。
分段翻译每次响应的 SSE 总量上限为 10 MiB。
普通翻译不支持 SSE 时会按同一流式协议使用配置的重试额度，仍失败则显示错误，不追加非流式请求。SSE 和 JSON 解析均有大小上限，异常流不会无限占用内存。

地址中的查询参数会被保留，例如兼容 Azure 风格网关所需的 `api-version`。携带 API Key
时，远程地址必须使用 HTTPS；仅 `localhost`、`127.0.0.0/8` 和 `[::1]` 允许 HTTP。

“测试连接”由受信任的扩展设置页直接请求用户配置的 API，可在当前
Network 面板查看请求和服务商返回。正式网页翻译仍由扩展后台发起，API Key 不会
进入网页内容脚本。测试成功只代表接口可访问、响应结构可解析且没有原样回显测试文本；
设置页会展示实际测试译文，最终语言和质量由用户据此确认。

自定义翻译 Prompt 支持 `{{targetLanguage}}` 占位符。扩展会在发送前替换为阅读体验中
选择的目标语言，并固定追加网页防注入、请求 ID 和 JSON 响应规则；这些结构协议不会随
用户 Prompt 一起开放，避免译文无法安全映射回对应网页节点。修改 Prompt 会产生新的
IndexedDB 缓存空间，不会继续命中旧指令生成的译文。Prompt 最长 8000 个字符；一个网页
翻译会话开始后会固定本次使用的配置、目标语言和 Prompt，中途修改只对下一次翻译生效，
避免 AI 请求与缓存键使用不同配置。

## 界面与设置

- 界面支持简体中文、英文、法语、德语和阿拉伯语。设置页的“界面语言”默认跟随浏览器，其他语言环境使用英文；可手动选择，保存后同步更新已打开的界面、网页提示和右键菜单。
- 界面语言与翻译目标语言独立。切换界面语言保留未保存配置和当前翻译，不重新调用 API。阿拉伯语采用 RTL，网页原文和译文保持各自的方向。
- 浏览器扩展管理页的名称、介绍与快捷键说明由浏览器语言决定；扩展内手动选择不改变这些原生信息。中文名称为“只是翻译”，其他语言为 Just Translate。

- 工具栏弹窗集中提供翻译、停止／继续、翻译引擎、目标语言、双语／仅译文和此站自动翻译。免费通道旁会提示网页文本的接收方及非官方接口风险；停止保留已完成译文，“恢复原文”清除页面译文。
- 目标语言或当前翻译引擎改变后，已有译文会保留。点击“用新设置重新翻译”才会取消旧任务、恢复网页并开始新任务；再次打开弹窗仍会提示设置差异。显示方式保存成功后立即应用，不发起翻译请求。
- “AI 配置”区分正在编辑与当前启用的配置。每个配置保留未保存草稿，切换栏目不会丢失；关闭页面前提示未保存内容。连接测试显示实际译文与耗时，修改字段后原测试结果失效。
- “阅读偏好”和“站点规则”自动保存，每项显示保存状态和失败重试，不受未完成 AI 草稿影响。自定义目标语言在失焦或回车时提交。
- 自动翻译仅匹配精确域名；不翻译支持精确域名和通配子域名。冲突时不翻译优先，两个列表都会保留原规则。
- 译文继承网页排版。失败段落保留原文，可点击“翻译失败 · 重试”，也可使用 Enter 或空格。服务商错误详情仅显示在扩展弹窗。
- 设置页在窄窗口切换为顶部导航与单列布局，所有界面跟随系统深浅色，并支持减少动态效果。

## 本地开发

需要 Node.js 22.12 或更高版本，项目固定使用 pnpm 10。构建打包使用系统的 `zip` 和 `unzip` 命令（macOS 自带；其他环境需提前安装并加入 PATH）。

```bash
npx -y pnpm@10.34.5 install
npx -y pnpm@10.34.5 test
npx -y pnpm@10.34.5 build
```

`pnpm build` 会自动递增 `package.json` 的版本号，并让构建产物使用同一版本：

- 版本格式为 `主版本.次版本.小版本`，次版本和小版本采用百位进制，例如 `0.3.98 → 0.3.99 → 0.4.0`。
- 次版本即将超过 99，或当前已大于 99 时，终端询问是否将主版本加 1、后两段归零（如 `0.99.99 → 1.0.0`）；只有输入 `y` 或 `yes` 才继续，默认取消。
- 非交互环境遇到主版本升级会阻断构建，提示在交互式终端确认，不会自动同意。
- 构建成功后，在项目根目录自动生成 `just-translate-v<版本号>.zip`，仅打包 `dist` 内容，`manifest.json` 位于 ZIP 根目录，可解压后加载或上传扩展商店。
- ZIP 通过完整性和包内版本校验后才输出最终文件；同版本旧包会被完整替换，不会混入旧文件。
- 类型检查失败不修改版本；打包、产物校验或 ZIP 生成失败时恢复原版本。失败后不要使用 `dist`，重新构建成功后再加载。

完整校验：

```bash
npx -y pnpm@10.34.5 check
```

`pnpm check` 执行 lint、测试、类型检查与构建校验，但不递增版本号。

### 性能诊断与浏览器验收

在扩展 Service Worker 的控制台中，对目标网页发送只读诊断命令：

```js
const [tab] = await chrome.tabs.query({ active: true, currentWindow: true });
await chrome.tabs.sendMessage(tab.id, { type: 'GET_PAGE_DIAGNOSTICS' });
```

诊断仅在当前页面会话内聚合阶段耗时：DOM 发现、配置预检、候选/缓存解析、后台排队、HTTP 请求、顺序等待和渲染。
`firstContent` 和 `firstValidSegment` 分别记录每次 HTTP 尝试到首个非空正文增量、首个通过校验的完整分段的时间；两者都不包括排队时间。
每阶段输出次数、累计时间和最大时间，不记录原文、Prompt、API 地址或 Key，不持久化或上传。
并发阶段累计耗时不能直接相加当作整页耗时；`elapsedMs` 在会话完成或停止时固定。
`firstTranslationMs` 是第一条译文实际提交到 DOM 的耗时；`batches` 统计页面派发的逻辑批次数、分片数与原文字符总量，`cacheHitNodes` 统计缓存命中节点。
逻辑批次数不等于 HTTP 次数：后台的自动重试和缺项补译会增加 HTTP 尝试，需结合 `request` 阶段和 Network 判断。

`node scripts/browser-fixture-server.mjs` 启动仅监听 127.0.0.1 的验收服务，输出随机端口。
`/news` 提供 60 条 HN 结构标题，`/article` 覆盖文章标题、flex 和保护片段；`/v1/chat/completions` 为模拟 API。
`/scenario?mode=normal|partial|fail|fail-once|slow|stream|disconnect|json` 切换正常、缺段补译、持续失败、首次失败后成功、慢响应、逐段流式、首批中途断流和不支持 SSE 场景，`/stats` 返回请求计数、并发上限、取消数与模拟请求的 ID。
使用隔离浏览器配置加载 `dist`；验证 HN 站点规则时，将 HN 文档请求映射到 `/news` fixture。
该服务不是真实翻译模型，不能据此声称服务商推理速度提升。


## 隐私与权限

- API Key 保存在 `chrome.storage.local`。
- 活跃翻译会话的配置快照暂存在 `chrome.storage.session`，页面会话结束、导航或标签页关闭后清理。
- `webNavigation` 仅用于校验当前文档及清理旧页面任务，不记录或上传浏览历史。
- `scripting` 仅在点击快捷翻译时，向当前普通网页独立加载翻译弹窗，不依赖网页翻译的连接状态；网站访问范围仍为 HTTP/HTTPS。
- 扩展后台将存储访问限制为 `TRUSTED_CONTEXTS`，网页内容脚本不能读取密钥。
- 翻译请求由扩展后台直接发往当前选中的 Google、Microsoft 或自定义 AI 服务，不经过开发者服务器。
- Google 免费通道使用 `translate.googleapis.com`；Microsoft 免费通道先从 `www.bing.com` 或 `cn.bing.com` 的 Translator 页面取得短期令牌，再向同一 Bing 主机翻译。请求不携带浏览器 Cookie、不读取微软账号，也不执行页面远程脚本。
- 译文缓存键使用 SHA-256，不在 IndexedDB 中保存 API Key 或明文原文。
- API 错误信息会截断并移除配置中的 API Key，避免把密钥带到界面或日志。
- 网页文本会发送给当前明确选择的翻译服务；免费消费端接口可能限流或变更。不要在敏感站点上启用，或将它们加入排除列表。

## 当前边界

当前版本处理普通 HTML 网页的正文与内容区界面文案，暂不处理 PDF、视频字幕、Shadow DOM 和网页图片的自动翻译；图片翻译通过快捷翻译手动上传，要求所选 AI 模型支持图片输入。输入值、placeholder、编辑区、图片和图标不参与整页翻译；导航、网站页眉页脚、侧栏、代码块和明确禁止翻译的内容仍被排除。表单中的可见标签与说明、内容区 ARIA 控件及挂载到 body 的可见菜单／对话框可以翻译，不改写控件本身的交互和布局。浏览器内置页和扩展商店禁止内容脚本注入。

扩展只在网页 `lang` 声明匹配，或较长文本的本地语言判定同时满足高置信度和明显领先幅度时，
才跳过已属于目标语言的内容。短文本、混合语言和不确定结果仍会发送给当前翻译引擎，优先避免漏翻。
