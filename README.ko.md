# Just Translate

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | **한국어** | [العربية](README.ar.md)

Chrome / Edge용 로컬 우선 이중 언어 웹 페이지 번역 확장 프로그램입니다. 번역문이 각 문단 바로 아래에 표시되어 원문과 번역문을 나란히 읽을 수 있고, 번역문만 보기로 전환할 수도 있습니다.

계정도, 로그인도, 구독도 필요 없습니다. 설치하면 바로 Google 또는 Microsoft 무료 채널로 번역할 수 있고, 자신의 OpenAI Chat Completions API나 Anthropic Messages API를 연결할 수도 있습니다. 요청은 확장 프로그램에서 선택한 서비스로 직접 전송되며 개발자 서버를 거치지 않습니다.

![일본어 기사를 영어로 번역해 각 문단 아래에 번역문을 표시한 화면](docs/images/bilingual.png)

## 왜 만들었나

웹 페이지 번역은 단순한 작업인데도, 대부분의 이중 언어 번역 확장 프로그램은 사용하기 전에 계정을 만들고 로그인하라고 요구합니다. Just Translate는 그 과정을 없앴습니다. 설치하고 바로 읽기 시작하면 됩니다.

## 주요 기능

- **이중 언어 읽기**: 번역문이 원문 문단 아래에 페이지의 서식을 그대로 이어받아 표시됩니다. "원문 + 번역문"과 "번역문만"을 전환할 수 있습니다.
- **설정 없는 무료 엔진**: Google 번역(기본값)과 Microsoft Translator는 계정, API 키, 브라우저 쿠키가 필요 없습니다.
- **나만의 AI 연결**: OpenAI, Anthropic, Gemini, Grok, Kimi, GLM, Xiaomi MiMo, DeepSeek, Qwen 및 `localhost` 로컬 서버를 포함한 호환 엔드포인트를 지원합니다. 프로필마다 프롬프트와 사고(thinking) 설정을 따로 지정할 수 있습니다.
- **전체 문서 번역**(AI 전용): 불러온 본문 전체를 한 번의 요청으로 보내 문단 간 용어와 지시어를 일관되게 유지합니다.
- **선택 영역 번역**: 텍스트를 선택하고 마우스 오른쪽 버튼을 누르면 선택 영역 옆 팝오버에 결과가 표시됩니다. iframe과 편집 가능한 영역에서도 동작합니다.
- **빠른 번역**: 붙여 넣은 텍스트를 바로 번역합니다. 이미지 입력을 지원하는 AI 모델이라면 이미지도 번역할 수 있습니다.
- **보이는 영역 우선**: 화면에 보이는 내용을 먼저 번역하고, 다음 화면, 나머지 순서로 진행합니다. 동적으로 추가된 콘텐츠도 점진적으로 번역합니다.
- **사이트 규칙**: 특정 도메인 자동 번역, 도메인이나 `*.example.com` 와일드카드로 제외.
- **로컬 캐시**: 번역문은 SHA-256 키로 IndexedDB에 72시간 동안 캐시됩니다.
- **몰래 엔진을 바꾸지 않음**: 엔진이 실패해도 페이지 텍스트를 다른 서비스로 조용히 다시 보내지 않습니다. 재시도나 전환은 사용자가 결정합니다.
- `Alt + T` 단축키, 라이트 / 다크 테마. UI는 영어, 중국어 간체, 프랑스어, 독일어, 아랍어를 지원합니다.

## 개인정보

- 개발자 서버를 전혀 거치지 않습니다. 요청은 확장 프로그램 백그라운드에서 Google, Microsoft 또는 설정한 AI 엔드포인트로 직접 전송됩니다.
- API 키는 `chrome.storage.local`에 저장되며 확장 프로그램의 신뢰할 수 있는 컨텍스트에서만 읽을 수 있습니다. 웹 페이지의 콘텐츠 스크립트는 접근할 수 없습니다.
- 캐시에는 API 키도, 원문의 평문도 저장하지 않습니다.
- 문단 안의 코드와 `translate="no"` 부분은 로컬 자리표시자로 바뀌어 번역 서비스로 전송되지 않습니다.

무료 채널은 공식 Google Cloud Translation / Azure Translator API가 아니라 일반 사용자용 웹 엔드포인트(`translate.googleapis.com`과 Bing Translator)를 사용합니다. 속도 제한이 걸리거나 변경되어 작동하지 않을 수 있습니다. 민감한 사이트에서는 번역을 켜지 않거나 제외 목록에 추가하세요.

자세한 내용은 [PRIVACY.md](PRIVACY.md)(중국어)를 참고하세요.

## 설치

소스에서 빌드합니다(Node.js 22.12 이상):

```bash
npx -y pnpm@10.34.5 install
npx -y pnpm@10.34.5 build
```

그다음:

1. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. "압축해제된 확장 프로그램을 로드합니다"를 누르고 `dist` 디렉터리를 선택합니다.
4. 아무 HTTP/HTTPS 페이지를 열고 툴바 아이콘을 누르거나, 마우스 오른쪽 메뉴에서 번역을 시작합니다.

AI 엔진을 쓰려면 확장 프로그램 설정 → "AI 설정"에서 공급자를 고르고 API 키를 붙여 넣으세요.
