# Just Translate

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | **العربية**

إضافة لمتصفحَي Chrome وEdge لترجمة صفحات الويب ثنائية اللغة، تعمل محليًا أولًا. تظهر الترجمة مباشرةً أسفل كل فقرة، فتقرأ النص الأصلي والترجمة جنبًا إلى جنب، أو تنتقل إلى عرض الترجمة وحدها.

لا حساب، ولا تسجيل دخول، ولا اشتراك. تعمل فور التثبيت عبر قناتَي Google وMicrosoft المجانيتين، ويمكنك أيضًا ربط واجهة OpenAI Chat Completions أو Anthropic Messages الخاصة بك. تُرسَل الطلبات مباشرةً من الإضافة إلى الخدمة التي اخترتها، ولا تمر عبر أي خادم للمطوّر.

![مقالة يابانية مترجمة إلى الإنجليزية، وتظهر ترجمة كل فقرة أسفلها](docs/images/bilingual.png)

## لماذا صنعناها

ترجمة صفحة ويب مهمة بسيطة، ومع ذلك تطلب معظم إضافات الترجمة ثنائية اللغة إنشاء حساب وتسجيل الدخول قبل استخدامها. تتخطى Just Translate هذه الخطوة: ثبّتها وابدأ القراءة.

## الميزات

- **قراءة ثنائية اللغة**: تظهر الترجمة أسفل الفقرات الأصلية وتحافظ على تنسيق الصفحة. يمكنك التبديل بين "الأصل + الترجمة" و"الترجمة فقط".
- **محرّكات مجانية دون إعداد**: لا تحتاج قناتا Google Translate (الافتراضية) وMicrosoft Translator إلى حساب أو مفتاح API أو ملفات تعريف الارتباط.
- **استخدم ذكاءك الاصطناعي الخاص**: OpenAI وAnthropic وGemini وGrok وKimi وGLM وXiaomi MiMo وDeepSeek وQwen، أو أي واجهة متوافقة، بما فيها الخوادم المحلية على `localhost`. لكل ملف تعريف موجّه (prompt) وإعدادات تفكير خاصة به.
- **ترجمة المستند كاملًا** (للذكاء الاصطناعي فقط): يُرسَل النص المحمَّل كله في طلب واحد، فتبقى المصطلحات والإحالات متّسقة بين الفقرات.
- **ترجمة النص المحدَّد**: حدّد نصًّا وانقر بزر الفأرة الأيمن، فتظهر النتيجة في نافذة منبثقة بجوار التحديد. تعمل داخل إطارات iframe والحقول القابلة للتحرير.
- **الترجمة السريعة**: نافذة لترجمة النص الملصَق، إضافةً إلى ترجمة الصور مع نماذج الذكاء الاصطناعي التي تدعم الصور.
- **الأولوية لما يظهر على الشاشة**: يُترجَم ما تراه أولًا، ثم الشاشة التالية، ثم الباقي. ويُترجَم المحتوى الديناميكي تدريجيًا.
- **قواعد المواقع**: ترجمة تلقائية لنطاقات محددة، واستبعاد نطاقات أو أنماط مثل `*.example.com`.
- **ذاكرة تخزين محلية**: تُخزَّن الترجمات في IndexedDB بمفاتيح SHA-256 لمدة 72 ساعة.
- **لا تبديل صامت للمحرّك**: إذا فشل محرّك ما، فلن يُعاد إرسال نص الصفحة إلى خدمة أخرى دون علمك. أنت من يقرّر إعادة المحاولة أو التبديل.
- اختصار `Alt + T`، ومظهر فاتح وداكن، وواجهة بالإنجليزية والصينية المبسطة والفرنسية والألمانية والعربية.

## الخصوصية

- لا يوجد أي خادم للمطوّر. تُرسَل الطلبات مباشرةً من خلفية الإضافة إلى Google أو Microsoft أو واجهة الذكاء الاصطناعي التي ضبطتها.
- تُحفَظ مفاتيح API في `chrome.storage.local`، ولا يمكن قراءتها إلا من سياقات الإضافة الموثوقة، ولا تصل إليها سكربتات صفحات الويب.
- لا تحتوي ذاكرة التخزين على مفاتيح API ولا على النص الأصلي بصيغة مقروءة.
- تُستبدَل الشيفرات والأجزاء الموسومة بـ `translate="no"` داخل الفقرات بعناصر نائبة محلية، ولا تُرسَل إلى خدمة الترجمة.

تستخدم القنوات المجانية واجهات ويب مخصّصة للمستخدمين العاديين (`translate.googleapis.com` وBing Translator)، وليست واجهتَي Google Cloud Translation أو Azure Translator الرسميتين، لذا قد تُقيَّد أو تتغيّر أو تتوقف. لا تفعّل الترجمة على المواقع الحساسة، أو أضفها إلى قائمة الاستبعاد.

راجع [PRIVACY.md](PRIVACY.md) (بالصينية) للتفاصيل.

## التثبيت

ابنِ الإضافة من المصدر (Node.js 22.12 أو أحدث):

</div>

```bash
npx -y pnpm@10.34.5 install
npx -y pnpm@10.34.5 build
```

<div dir="rtl">

ثم:

1. افتح `chrome://extensions` في Chrome أو `edge://extensions` في Edge.
2. فعّل وضع المطوّر.
3. انقر "تحميل إضافة غير مضغوطة" واختر مجلد `dist`.
4. افتح أي صفحة HTTP/HTTPS وانقر أيقونة شريط الأدوات، أو ابدأ الترجمة من قائمة النقر بزر الفأرة الأيمن.

لاستخدام محرّك ذكاء اصطناعي، افتح إعدادات الإضافة ← "إعدادات الذكاء الاصطناعي"، واختر المزوّد والصق مفتاح API.
